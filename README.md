# 데이터 시각화 커리큘럼

[Vega-Lite](https://vega.github.io/vega-lite/)와 [Altair](https://altair-viz.github.io/)를 사용하는 대화형 노트북으로 구성된 데이터 시각화 커리큘럼입니다. 이 저장소에는 [Jupyter](https://jupyter.org/)와 [marimo](https://marimo.io/)를 사용하는 일련의 **Python** 노트북이 포함되어 있습니다. 노트북은 [Jupyter book](https://uwdata.github.io/visualization-curriculum/intro.html)에서 온라인으로 볼 수 있으며, 로컬에서 실행하거나 [Colab](https://colab.research.google.com/github/uwdata/visualization-curriculum), [Nextjournal](https://github.nextjournal.com/uwdata/visualization-curriculum), [Deepnote](https://deepnote.com/launch?url=https://github.com/uwdata/visualization-curriculum/blob/master/altair_introduction.ipynb), 또는 [molab](https://marimo.io/for-learners#learn-altair)에서 온라인으로 실행할 수 있습니다. 해당되는 **JavaScript** 노트북 세트는 [Observable](https://observablehq.com/@uwdata/data-visualization-curriculum)에서 온라인으로 이용 가능합니다.

## 시작하기

시각화 커리큘럼은 온라인이나 로컬 컴퓨터에서 사용할 수 있습니다.

### 온라인

- [Jupyter Book](https://uwdata.github.io/visualization-curriculum/)에서 온라인으로 Python 노트북을 읽을 수 있습니다.
- [Colab](https://colab.research.google.com/github/uwdata/visualization-curriculum/), [Nextjournal](https://github.nextjournal.com/uwdata/visualization-curriculum/), 또는 [Deepnote](https://deepnote.com/launch?url=https://github.com/uwdata/visualization-curriculum/blob/master/altair_introduction.ipynb)에서 온라인으로 **Python** 노트북을 실행할 수 있습니다.
- [Observable](https://observablehq.com/collection/@uwdata/visualization-curriculum)을 사용하여 온라인으로 **JavaScript** 노트북을 실행할 수 있습니다.
- [molab](https://marimo.io/for-learners#learn-altair)을 사용하여 온라인으로 **marimo** 노트북을 실행할 수 있습니다.

### 로컬 설치

1. [Altair 및 노트북 환경을 설치합니다](https://altair-viz.github.io/getting_started/installation.html). 이 노트북의 최신 버전은 _Altair 버전 6_을 사용합니다.
2. [릴리스 페이지](https://github.com/uwdata/visualization-curriculum/releases)에서 노트북을 다운로드합니다. 일반적으로 최신 릴리스를 사용하는 것이 좋습니다.
3. [Jupyter](https://jupyter.org/)를 사용하는 경우 로컬 노트북 환경에서 `.ipynb` 노트북을 엽니다. 예를 들어 JupyterLab이 설치되어 있는 경우(v1.0 이상 필요), 노트북이 포함된 디렉토리 내에서 `jupyter lab`을 실행하십시오. [uv](https://docs.astral.sh/uv/guides/install-python/)를 사용하는 경우 `uv run jupyter lab`을 실행할 수 있습니다(종속성이 자동으로 설치됩니다).
4. [marimo](https://marimo.io/)를 사용하는 경우 `marimo run marimo/notebook.py`(설정한 가상 환경 사용) 또는 `uv run marimo run marimo/notebook.py`(노트북 헤더의 종속성을 자동으로 설치)를 사용하여 `marimo` 디렉토리의 `.py` 노트북을 엽니다.

프로그래밍 환경(및 실시간 인터넷 연결 여부)에 따라 Altair를 위한 특정 [렌더러](https://altair-viz.github.io/user_guide/display_frontends.html)를 지정해야 할 수도 있습니다.

### Jupyter Book 게시하기

이 책은 [Jupyter Book 2](https://jupyterbook.org/)로 빌드되며 GitHub Actions를 통해 `translate-korean` 브랜치에 푸시할 때마다 GitHub Pages에 자동으로 게시됩니다.

로컬에서 책을 미리 보려면:

```bash
uv run jupyter-book start
```

수동으로 게시하려면:

```bash
uv run jupyter-book build --html
npx -y gh-pages -n -d _build/html
```

빌드 중에 노트북을 실행하려면 `--execute` 플래그를 추가하십시오:

```bash
uv run jupyter-book build --execute --html
```
